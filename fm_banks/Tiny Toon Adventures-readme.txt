This is a General MIDI bank built from importend instruments found the "Tiny
Toon Adventures" game for Sega Megadrive, and some instruments were been
imported from the "gems-fmlib-gmize" bank as they were been missing in the set.

License for this bank - MIT

To edit this bank and other banks in WOPL format, you can use this editor
which I created for that: https://github.com/Wohlstand/OPL3BankEditor
