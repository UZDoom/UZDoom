This is "The Fat Man" like bank which is an attempt to replicate the sounding of
the similar bank widely used in cell phones industry with chips like Yamaha MA-2,
MA-3, MA-5, etc. It has very close sounding since operator setup are very and
very similar with OPL family, and therefore it was possible to replicate the
bank except of some minor differences.

The name of the bank is from Russian word "мобильник" which is an informal
referring of a "cell phone".

This bank can be freely used, modified, shared with any purposes.

License for this bank - MIT as the original The Fat Man bank is licensed under
terms of the MIT license, details are here: https://github.com/Wohlstand/TheFatManOPL

To edit this bank and other banks in WOPL format, you can use this editor
which I created for that: https://github.com/Wohlstand/OPL3BankEditor
